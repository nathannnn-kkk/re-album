# RE:ALBUM

A browser-based album visual remix studio for pop music fans. Choose a visual starting point, edit the artwork in your browser, and export cover, vinyl, and social images.

**Live site:** [Open RE:ALBUM](https://nathannnn-kkk.github.io/re-album/)

## Run locally

```sh
cd RE-ALBUM-publish
npm run dev
```

The app uses browser-native APIs and Node.js built-in modules; no third-party packages are required.

## Project files

The application source and product documentation are in [`RE-ALBUM-publish/`](./RE-ALBUM-publish/). Product documents are in [`RE-ALBUM-publish/docs/`](./RE-ALBUM-publish/docs/).
