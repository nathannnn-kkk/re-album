# 01｜产品定位与目标用户

## 1. 产品定位

**一句话：** RE:ALBUM 是为欧美流行音乐粉丝设计的在线专辑视觉再创作工具，让用户通过原创模板与轻量编辑，把音乐带来的情绪和身份认同转化为个人视觉表达。

**产品承诺：** 选一个灵感模板，换上自己的图像和文字，几分钟内得到一张可分享的原创视觉作品。

**作品集目标：** 展示从用户问题、产品边界、交互设计、前端实现到版权意识的完整产品决策能力。

## 2. 问题与机会假设

- 粉丝会围绕专辑视觉、艺人时代（era）和歌词情绪进行二创，但从空白画布开始需要设计经验和时间。
- 通用设计软件功能丰富，却要求用户自己寻找版式和建立视觉方向。
- 单一专辑生成器通常只支持一种固定结果；粉丝希望既能快速套用，也能做个人化调整。
- 专辑图像、艺人肖像、标识和歌词涉及权利边界，创作工具需要从素材来源和分享方式上建立清晰规则。

这些是待验证假设，不应在作品集材料中写成已完成市场研究结论。

## 3. 目标用户

### 核心用户：轻度创作型粉丝

喜欢欧美流行音乐，经常浏览或分享粉丝内容；希望表达对某个专辑或音乐情绪的喜爱，但没有 Photoshop 等专业工具经验。

**目标：** 快速得到有“专辑视觉感”、同时带有个人表达的图像。  
**障碍：** 不知道如何排版；编辑器复杂；现成生成器个性化空间少；素材权利不清楚。

### 次级用户：Fan editor / 创意粉丝

已有基础修图或拼贴经验，希望从模板起步并调整字体、颜色、图层和构图。

**目标：** 快速建立可继续加工的构图，并控制创作细节。  
**障碍：** 模板锁定、尺寸不合适、导出质量不足。

### 暂不优先

- 专业平面设计师：通常已有偏好的工具和精细控制需求。
- 寻找官方艺人素材或官方合作的用户：本产品不代表艺人、唱片公司或版权方。

## 4. 核心用户需求与场景

1. **快速表达：** 我刚听完一张专辑，想做一张有相关氛围的图发给朋友或社交平台。
2. **低门槛改编：** 我想把封面上的主标题改成自己的短句，保留视觉秩序。
3. **个人化：** 我想换成自己的照片、插画或有授权的素材，并调整颜色与排版。
4. **可控交付：** 我想知道作品会以什么尺寸导出，且不必注册账号或上传到公共社区。

## 5. 竞品差异化假设

| 选择 | 用户优势 | RE:ALBUM 可验证的差异假设 |
|---|---|---|
| Canva / 通用设计工具 | 模板、编辑能力丰富 | 以音乐粉丝的表达场景组织模板与字段，减少从空白画布到成稿的决策步骤 |
| 单艺人/单专辑 generator | 主题鲜明、操作快 | 提供多种原创音乐视觉方向和可替换的通用内容结构，避免绑定单一艺人资产 |
| 通用 AI 图片生成器 | 生成自由度高 | 以可预期、可编辑的版式为中心，让用户控制文字、图片位置与导出结果 |
| Photoshop 等专业软件 | 控制细、能力强 | 将常见粉丝视觉创作压缩为轻量流程，减少学习成本 |

以上为产品假设，MVP 通过可用性测试、任务完成时间、完成率和用户偏好进行验证，不宣称已经优于竞品。

## 6. 产品原则

- **音乐文化优先：** 按创作意图和情绪寻找模板，而非堆砌编辑器工具。
- **先有好结果：** 初始模板的排版应完整、有层次；用户不编辑也能得到合理预览。
- **修改可逆：** 编辑操作可撤销/重做，重置前有明确提示。
- **用户掌控素材：** 上传图片在本地浏览器处理；导出前展示作品预览。
- **清晰表达权利边界：** 使用原创或许可素材，不暗示官方授权。
