# 02｜产品需求文档（PRD）

## 1. 范围与版本

MVP 为响应式 Web 应用，单次会话内完成模板选择、编辑、预览和本地 PNG 导出。默认不持久化用户作品；刷新页面后不承诺恢复草稿。

### MVP 范围

- 首页价值说明和模板入口。
- 模板浏览、分类、预览及进入编辑器。
- 快速编辑模式：模板预设字段、照片替换、主题变体、即时预览。
- 自由编辑模式：有限图层选择与调整，包括文字内容、位置/字号、颜色、图片裁切与背景色。
- 撤销/重做、重置、导出 PNG。
- 上传格式/尺寸提示、错误与空状态、移动端基本适配。
- 版权与素材说明、隐私说明。

### 非目标

- AI 生成人像、换脸、模仿具体艺人或在世艺术家的风格。
- 官方专辑封面、艺人肖像、唱片公司标识或歌词库的内置分发。
- 用户账号、云端保存、公开作品社区、评论/点赞、模板市场。
- 复杂图层蒙版、专业级色彩管理、印刷级 CMYK 工作流。
- 自动抓取流媒体内容、歌词或艺人资料。

## 2. 用户故事、需求与验收标准

### US-01：浏览和选择模板（P0）

作为粉丝，我想按视觉方向浏览模板，以便快速找到适合当前情绪的起点。

**功能需求**

- 模板卡显示预览图、模板名称、简短风格描述、建议用途和可编辑能力标记。
- 提供少量清晰分类（例如情绪 / 视觉形式），并支持无结果状态。
- 选择模板后进入该模板的编辑器，保留模板标识。

**验收标准**

- 键盘用户可聚焦并打开模板卡，卡片有可见焦点状态。
- 模板缩略图加载失败时仍可读出名称、说明并进入编辑。
- 选择模板后，编辑器显示正确的模板预览和名称。

### US-02：快速修改模板（P0）

作为不熟悉设计软件的粉丝，我想改文字、上传图片并立即看到结果。

**功能需求**

- 表单字段由模板 schema 提供，支持单行文字、多行文字、颜色/主题选项和图片上传。
- 每次输入都更新画布预览；可重置为模板初始值。
- 文本长度限制应在控件旁说明；超限时阻止继续输入或显示明确提示。

**验收标准**

- 修改标题后，预览中的对应标题更新，其他字段不变。
- 输入为空时使用模板定义的空值策略（隐藏字段或显示占位提示），不得溢出版面。
- 重置后所有字段和预览回到模板初始状态。

### US-03：替换并裁切图片（P0）

作为创作者，我想使用自己提供的图片并控制裁切。

**功能需求**

- 接受 JPEG、PNG、WebP、AVIF，以及当前浏览器可解码的 HEIC/HEIF；根据 MIME 类型和扩展名校验，单张图片上限 25 MB。
- 图片本地读取并进入指定图片槽；提供适配容器的 cover / contain 行为与水平、垂直焦点调整。
- 替换图片、清除图片；对不支持格式、读取失败和超限文件给出具体提示。

**验收标准**

- 合法图像出现在所选槽位且保持正确比例，不拉伸。
- 非图像文件、损坏文件或超过上限的文件不会被渲染，并显示可理解的错误。
- 页面不向任何后端传输上传文件；用户可移除图片并恢复模板占位背景。

### US-04：切换自由编辑模式（P1）

作为有创作经验的粉丝，我想调整元素细节。

**功能需求**

- 切换快速/自由模式时不丢失当前编辑状态。
- 自由模式可选择可编辑图层，调整文本位置、字号、颜色及图片焦点；不可编辑的品牌/版权说明层明确标注。
- 编辑面板在窄屏下可折叠，预览保持可见。

**验收标准**

- 模式切换前后的用户输入一致。
- 修改某图层属性只影响该图层。
- 小屏下可访问所有控件，页面不产生不可操作的横向溢出。

### US-05：撤销、重做与重置（P1）

作为创作者，我想试错并能恢复操作。

**功能需求**

- 编辑操作加入有序历史；Undo/Redo 按钮展示禁用状态。
- 重置恢复模板默认配置，执行前二次确认或提供可撤销提示。

**验收标准**

- 连续编辑后逐步撤销可回到此前状态；重做可恢复撤销内容。
- 历史为空时撤销禁用，位于最新状态时重做禁用。
- 重置覆盖当前编辑状态前有明确告知。

### US-06：导出 PNG（P0）

作为创作者，我想下载成品并用于个人分享。

**功能需求**

- 导出所见即所得的作品画布，不包含编辑器 UI。
- 提供固定的方形社交尺寸（MVP 目标 1080×1080 px）和清晰度说明。
- 导出中、成功、失败均有状态；文件名使用通用项目名，不默认写入艺人名。
- 清晰告知用户其输入素材权利责任和导出作品的用途边界。

**验收标准**

- PNG 文件尺寸为 1080×1080 px，透明/背景行为由模板定义且一致。
- 导出结果中所有文字、裁切和颜色与预览一致，无 UI 元素或意外留白。
- 导出失败时保留编辑状态并提供重试方式。

### US-07：理解素材与隐私边界（P0）

作为用户，我想知道上传图像如何处理，以及是否获得官方授权。

**功能需求**

- 上传入口旁明确“仅在当前浏览器会话处理，不上传服务器”（实现需符合该描述）。
- 页脚和导出说明声明 RE:ALBUM 为独立粉丝创作工具，与艺人、唱片公司及平台无隶属关系。
- 提供素材投诉/联系渠道占位，发布前补齐真实联系信息和流程。

**验收标准**

- 用户上传前能找到处理方式说明。
- 页面和导出图不出现未经许可的艺人素材或官方徽标。
- 所有内置图片、字体、图标均有记录的来源和许可。

### US-08：将专辑视觉延展为黑胶展示图（P1）

作为粉丝，我想把当前封面延展为唱片与封套组合图，以便分享一套更完整的专辑视觉。

**功能需求**

- 编辑器提供“Cover / Vinyl visual / Share image”成品切换；黑胶展示图复用当前封面、标题、字体和主题色。
- 用户可选择黑胶颜色（黑色、主题色、珊瑚色、蓝色）、唱片与封套的前后关系，以及是否显示曲目。
- 曲目仅使用用户已编辑或模板现有字段中的内容；没有曲目资料时不显示虚构曲目。
- 黑胶展示图以 1080 × 1080 PNG 导出，并说明这是数字分享图，不是印刷生产文件。
- 重置黑胶展示图只重置该成品设置，不清除封面编辑。

**验收标准**

- 调整黑胶颜色、层次和曲目显示后预览即时更新。
- 切换回封面再返回黑胶展示图，封面和黑胶设置均保留。
- 导出 PNG 为 1080 × 1080，且只包含黑胶成品画布。

### US-09：制作社交分享图（P1）

作为粉丝，我想将当前专辑视觉排成社交平台常用尺寸，并补充自己的短评。

**功能需求**

- 支持方形 1080 × 1080、竖版 1080 × 1350、Story 1080 × 1920 三种尺寸。
- 支持 Cover first、Editorial、Type led 三种布局；切换尺寸后重新排版，不拉伸封面。
- 用户可编辑艺人/署名、100 字以内短评、栏目标签，并选择是否显示栏目标签和 1–5 星评分。
- 分享图设置与封面内容分开保存；切换成品或尺寸时不清空文字。
- 导出 PNG 使用当前画布尺寸；重置分享图只恢复分享图的默认设置。

**验收标准**

- 三种画布预览比例及 PNG 像素尺寸正确。
- 标题、署名、标签、评分和短评按布局显示；关闭选项后对应元素隐藏。
- 空短评、未上传图片或文字较长时仍能得到完整、可读的作品。
- 导出失败时保留当前设置和编辑状态。

## 3. 通用质量需求

- 页面在常见桌面与手机宽度下可用，核心按钮至少有键盘操作和可见焦点。
- 表单控件具备关联标签；错误提示与控件建立可读关联；颜色不是唯一状态提示。
- 预览更新应保持交互流畅；大图缩放到工作尺寸后处理，避免无界内存增长。
- 不记录用户图片、作品像素内容或输入文本到分析事件。
- 空模板列表、加载失败、导出失败、图片读取失败均提供恢复路径。

## 4. 验证指标（作品集原型阶段）

- 任务完成率：用户能否从首页完成选择、编辑、导出。
- 首次成稿时间：从选择模板到第一次成功导出的用时。
- 编辑成功率：用户能否完成“修改文字 + 替换图片”任务。
- 主观清晰度：用户能否解释快速模式和自由模式的区别。
- 失败分类：上传问题、找不到入口、文字溢出、导出偏差、权利说明不理解。

首轮可邀请 5–8 位目标用户进行观察式测试；这只是形成性可用性检查，不能代表统计显著的市场验证。
