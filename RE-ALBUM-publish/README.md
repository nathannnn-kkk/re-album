## 项目摘要

RE:ALBUM 是面向欧美流行音乐粉丝的专辑视觉二创工具。用户通过原创视觉模板、文字编辑、图片替换和风格参数，快速完成可下载的专辑灵感作品，并可将同一份创作延展为黑胶唱片展示图和多尺寸社交分享图。应用在浏览器内创作与导出 PNG，不依赖账号或服务端存储。

## 本地运行

当前原型使用浏览器原生能力和 Node.js 内置模块，不需要安装第三方依赖。

```sh
npm run dev
```

然后访问 `http://localhost:4173`。也可以直接在浏览器打开 `index.html`；交互脚本使用普通本地脚本加载，不要求模块服务器。生成静态生产文件：

```sh
npm run build
```

生产文件位于 `dist/`。构建只复制静态站点文件；部署时可将该目录交给任意静态文件托管服务。

## 当前产品决策

1. 产品目标是作品集（portfolio），首要证明完整产品思考与可用的创作体验。
2. 目标用户是欧美音乐粉丝，优先满足不具备专业设计技能的轻度创作者。
3. 产品是专辑文化导向的二创工具，不是通用 AI 图片生成器。
4. MVP 使用原创模板，支持文字编辑、用户图片替换、实时预览、PNG 导出。
5. 编辑体验包含快速模式和自由编辑模式；复杂 AI 换脸、社区、账号系统不进入 MVP。

## MVP 成功信号

可用性验证目标（需通过作品集测试校准）：首次用户无需说明即可完成模板选择、至少一项内容编辑和 PNG 导出；核心流程中断点可被观察和记录；导出图像尺寸、文字布局和上传图片裁切结果符合预期。
